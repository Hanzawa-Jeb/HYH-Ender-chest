# Sequences
- 是一个从整数集的子集到一个集合S的映射
- $a_n$就是n的image，$a_n$就是这个sequence中的一个term
- geometric progression就是一个等比数列
- arithmetic progression就是一个等差数列
- String就是一个finite sequence of characters，同样可以被$\{a_1a_2...a_n\}$ 来表示
# Recurrence Relations
- 就是一个递归数列，前项与后项之间**满足某种特定的关系**
- 如果一个具体的数列可以满足这种特定的迭代关系，那么就可以被称为是一个**Solution**
- initial conditions可以定义在首项之前，从而可以定义整个数列
- 可以从尾部开始迭代(backward substitution)，也可以从头开始迭代(forward substitution)
- fibonacci $f_0 = 0, \; f_1 = 1$
